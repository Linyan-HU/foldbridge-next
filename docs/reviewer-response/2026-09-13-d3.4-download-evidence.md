## 本次修改

- E/F Contact / pair map 下提供 `Download heatmap (SVG)` 和 `Download matrix data`。
- SVG 导出当前呈现的矩阵、坐标轴、色标和 PDB/chain/family；包含源 header、显示 header 和轴映射元数据。排除 hover、selection 和交互层，导出不改变页面选择。
- 矩阵数据使用加载器从 manifest 解析出的同一资源 URL，直接下载原 JSON.gz；E/F 切换对应不同文件，链 ID 保留大小写。
- SVG 是显示区域的图形；JSON.gz 是完整源矩阵。两者分母可以不同，不将显示区域当作完整数据。
- 延续现有 E/F hover、鼠标、键盘及跨视图联动，不修改数据、归一化或原始 RDAT 功能。
