## 可复制的浏览器测量方法

浏览器为 Codex in-app browser。测量脚本每 `200 ms` 检查一次条件，最长等待 `15 s`；
超时直接抛错并将该视口判为失败，不返回可误写成通过的测量值。普通路由至少等待
`document.readyState === 'complete'` 和路由目标 DOM 出现，再使用约 `800 ms` 的短暂 settle；
settle 只用于减少刚渲染后的抖动，不能替代条件等待。Case 路由先将
`.entry-case-embed-frame` 滚入视区触发懒加载，再等待 iframe 的 inline height 满足稳定条件，
不以固定时长作为最终完成条件。本轮使用的关键 selector 为：

- `.bundle-home-route-nav .nav-btn`
- `.site-search-form input,.site-search-form button`
- `.entry-table-wrap`
- `.entry-table`
- `.entry-case-embed-frame`

下列代码可在每个待测路由的浏览器控制台复制执行：

```js
await (async () => {
  const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
  const waitFor = async (predicate, label, { intervalMs = 200, timeoutMs = 15000 } = {}) => {
    const deadline = performance.now() + timeoutMs;
    while (performance.now() <= deadline) {
      if (await predicate()) return;
      await sleep(intervalMs);
    }
    throw new Error(`${label} timed out after ${timeoutMs} ms`);
  };

  await waitFor(
    () => document.readyState === 'complete',
    'document.readyState === complete',
  );

  const hash = location.hash;
  const isCase = hash.startsWith('#entry-case');
  const targetSelector = isCase
    ? '.entry-case-embed-frame'
    : hash.startsWith('#search')
      ? '.site-search-form'
      : hash.startsWith('#entry')
        ? '.entry-table-wrap'
        : '.bundle-hero-card';
  await waitFor(
    () => document.querySelector(targetSelector) !== null,
    `target DOM ${targetSelector}`,
  );

  const frame = document.querySelector('.entry-case-embed-frame');
  if (isCase) {
    frame.scrollIntoView({ block: 'center', inline: 'nearest' });
    let lastHeight = null;
    let stableSamples = 0;
    await waitFor(() => {
      const inlineHeight = frame.style.height;
      const validHeight = /^\d+(?:\.\d+)?px$/.test(inlineHeight)
        && Number.parseFloat(inlineHeight) > 0;
      if (frame.getAttribute('scrolling') !== 'no' || !validHeight) {
        lastHeight = null;
        stableSamples = 0;
        return false;
      }
      if (inlineHeight === lastHeight) {
        stableSamples += 1;
      } else {
        lastHeight = inlineHeight;
        stableSamples = 1;
      }
      return stableSamples >= 3;
    }, 'Case iframe scrolling=no and stable inline px height');
  } else {
    await sleep(800);
  }

  const selectors = [
    '.bundle-home-route-nav .nav-btn',
    '.site-search-form input,.site-search-form button',
    '.entry-table-wrap',
    '.entry-table',
    '.entry-case-embed-frame',
  ];
  const nodes = selectors.flatMap((selector) =>
    [...document.querySelectorAll(selector)].map((element) => ({ selector, element })),
  );
  const box = (element) => {
    const rect = element.getBoundingClientRect();
    return {
      left: rect.left,
      right: rect.right,
      top: rect.top,
      bottom: rect.bottom,
      width: rect.width,
      height: rect.height,
    };
  };
  const pairwiseOverlaps = (elements) => elements.flatMap((first, index) =>
    elements.slice(index + 1).flatMap((second) => {
      const a = box(first);
      const b = box(second);
      const overlapX = Math.max(0, Math.min(a.right, b.right) - Math.max(a.left, b.left));
      const overlapY = Math.max(0, Math.min(a.bottom, b.bottom) - Math.max(a.top, b.top));
      return overlapX > 1 && overlapY > 1 ? [{ overlapX, overlapY }] : [];
    }),
  );
  const documentElement = document.documentElement;
  const wrap = document.querySelector('.entry-table-wrap');
  const table = document.querySelector('.entry-table');
  const embed = document.querySelector('.entry-case-embed');
  const navButtons = [...document.querySelectorAll('.bundle-home-route-nav .nav-btn')];
  const searchControls = [
    ...document.querySelectorAll('.site-search-form input,.site-search-form button'),
  ];

  return {
    url: location.href,
    document: {
      clientWidth: documentElement.clientWidth,
      scrollWidth: documentElement.scrollWidth,
      horizontalPass: documentElement.scrollWidth <= documentElement.clientWidth,
      verticalScroll: documentElement.scrollHeight > documentElement.clientHeight,
    },
    elements: nodes.map(({ selector, element }) => {
      const rect = box(element);
      return {
        selector,
        rect,
        clippedByDocument: rect.left < 0 || rect.right > documentElement.clientWidth,
      };
    }),
    peerOverlaps: {
      navigation: pairwiseOverlaps(navButtons),
      search: pairwiseOverlaps(searchControls),
    },
    entry: wrap && table ? {
      wrapperClientWidth: wrap.clientWidth,
      wrapperScrollWidth: wrap.scrollWidth,
      tableScrollWidth: table.scrollWidth,
      wrapperOverflowX: getComputedStyle(wrap).overflowX,
    } : null,
    iframe: frame ? {
      scrolling: frame.getAttribute('scrolling'),
      inlineHeight: frame.style.height,
      overflowY: getComputedStyle(frame).overflowY,
      embedOverflowY: embed ? getComputedStyle(embed).overflowY : null,
      rect: box(frame),
    } : null,
  };
})();
```

验收判定为：`documentElement.scrollWidth <= clientWidth`；同组导航按钮和 Search 控件的
矩形两轴重叠均不得同时超过 `1 px`；外层元素不得满足 `left < 0` 或
`right > clientWidth`。移动端 `.entry-table` 宽于文档是预期行为，但必须由
`.entry-table-wrap` 的 `overflow-x: auto` 局部承接，并记录 wrapper 的
`clientWidth / scrollWidth`。Case 另记录 iframe 的 `scrolling` 属性、computed
`overflowY`、embed computed `overflowY` 与父文档纵向滚动状态。Case 只有在
`getAttribute('scrolling') === 'no'`、`style.height` 为非空正数 `px`，且该 inline height
连续至少 3 次采样不变后才返回报告；任一条件在 `15 s` 内未满足都会抛错并判失败。

可复现限制：CUA 未暴露该会话的 `navigator.userAgent` 或浏览器版本，本轮读取值为
`null`；因此证据只能固定为 Codex in-app browser、视口、URL、日期和上述 DOM 测量步骤，
不能进一步固定浏览器版本。

## C1.6：旧式 Extended PDB ID 搜索

### 原始复现

修复前，Search 服务将用户输入原样传给 Pagefind。`1DDY` 与旧式标识
`pdb_00001ddy` 因而不是同一个 Pagefind 查询，违背了两种标识应命中同一组链级 Case
结果的约定。该失败入口已由 `test/search-service.test.js` 中的边界测试固化。

### 最小修改

仅在 Pagefind 调用边界增加 `normalizeSearchQuery()`：

- 完整匹配 `^pdb_0000([0-9a-z]{4})$` 时，提取 4 位 PDB ID 并转为大写；
- 保留页面输入、URL 查询状态和返回对象中的原始用户查询；
- 普通文本和长度非法的相似字符串不转换；
- 不改 Pagefind 文档、筛选器、结果映射或链级 Case 路由。
