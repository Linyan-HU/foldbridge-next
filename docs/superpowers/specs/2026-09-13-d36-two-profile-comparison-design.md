# D3.6 一主多比较 Profile：最小设计

## 状态与目标

2026-09-13：用户已确认 1 个主 Profile 加最多 3 个自选比较 Profile。保留原文件名以延续引用；此修订取代两条上限；本文件不代表功能已实现或上线。

让用户在同一 PDB × chain 的共同残基坐标上，同时查看当前主 Profile 和最多 3 条已发布比较 Profile。第一版回答“这些位置分别观察到什么信号”，不自动判断一致性、显著性或结构变化原因。

## 范围与不做事项

- 只支持普通一维 Profile 模式，1 个主项加最多 3 个比较项。E/F 二维矩阵模式不增加比较控件，也不改变 D3.4 下载。
- 只从当前 Case 生产 profile index 中选择；严格保持链 ID 大小写。所有已选项必须属于同一 render strand，并与当前残基坐标及 strand 长度一致。
- 不新增后端、统计依赖、数据转换、原始 RDAT 请求、跨链对齐或 Case 数据重建。
- 不做差值、相关系数、散点图、显著性检验、实验分组、额外导出或两个结构查看器。
- 仅提供数据覆盖计数，不用它代替差异统计。接口中没有的探针、条件、重复信息不从文件名猜测，也不推断原始实验缺少这些信息。

## 交互

2026-09-13 用户追加确认：自选比较操作区默认折叠，点击 `Compare profiles (n/3)` 展开；折叠仅隐藏操作控件，不清空已选项或隐藏轨道，有比较时尺度提示继续显示。

1. 保留当前主 Profile 选择器，附近添加一个可搜索的 `Add comparison` 选择器，默认没有比较，不自动加载。候选来自同 strand 的公开 index，排除主项和已选项，沿用已有标签/ID 搜索。
2. 按添加顺序显示最多 3 个比较项；满额提示 `3/3` 并禁用添加。每项独立移除，移除后可补入，不增加确认刷新或排序操作。
3. Technique 筛选仍只执行现有功能，不自动改变比较候选或已选项。
4. 在现有主反应性行下方添加比较行，最多共 4 条信号行。共用同一个 SVG 横坐标与滚动容器；添加、移除、异步完成不重置横向滚动，不扩大页面宽度。
5. 标为 `Primary` 和 `Comparison 1–3`，显示完整 ID、已有方法标签、各自尺度及覆盖。长 ID 换行或提供可访问完整文本。
6. 比较行悬停/键盘聚焦仅显示自身位点、保存值、显示值、缺失状态，不改变主项、2D/3D 或 inspector。主项原有联动不变。
7. 没有合格候选时禁用添加并解释；零 Profile 保持空态。加载中与失败项独立提示，可移除，仍占一个名额；不画伪数据行。
8. 主项切换时保留仍合格且不重复的比较，移除失效项并解释，不自动替换。主项加载中暂停新增，不能混合新旧主项摘要。切换 Case/chain 时清空。

## 显示与科学边界

复用现有 `normalizeReactivityProfile` 与 C 类三状态渲染：缺失、实测有限非正值、正值。每条比较使用自己的现有 P95 显示尺度，不能用主 Profile 的尺度去重新标定比较 Profile。

所有信号行均明确显示各自 P95 上限，并共用提示：`Each profile is scaled independently for display. Compare positional patterns, not absolute signal magnitudes.` 保存值保持不变；此处“保存值”指网站 shard 中的输入值，不宣称它是未经实验处理的原始测量值。全缺失或没有正值时保留现有三状态，不制造数值信号或有效缩放上限。

允许跨方法查看，但不宣称不同方法的数值、颜色或强弱阈值可直接等同；不做跨技术统一归一化。

覆盖摘要固定以完整共同 strand 的 L 个位置为分母，显示主 Profile 有限值数 A/L、每个比较 Profile 有限值数 Bᵢ/L、该项与主项的共同有限值数 sharedᵢ/L（不是所有轨道交集）。有限的零值和负值均计入，NaN/Infinity 不计入；不声称这些位置全部已在三维结构中解析。`sharedᵢ=0` 时明确提示没有共同有效位置，仍允许查看各自覆盖。

## 数据流与错误处理

- 复用 `loadShard` 的已解压缓存和 `profileValues` 的单行读取；同 shard 并发请求复用进行中的 Promise，完成/失败后清除请求槽；不自动重试，不预加载每个候选的整条数据。
- 比较模型持有按添加顺序排列的最多 3 项，每项独立保存 ID、加载状态、保存值、显示结果及覆盖摘要；主状态 `lastRender` 不被比较操作覆盖。
- 加载前验证选择来自当前 index；加载后验证 strand 身份、行索引边界、数据长度及 shard 元数据。不截断、补零或悄悄换用其他 Profile。
- 请求以当前 Case/chain、主 Profile、上下文代次及每项独立请求 token 绑定；一项完成不取消其他项，移除再添加后旧响应也不得复活旧项。快速切换、取消或退出页面后，过期响应不得重绘当前比较。复用缓存不豁免身份验证。
- 加载过程中不把上一条的轨道或统计显示为新选择。单项失败只清除该项的失效显示并提示错误，其他比较不受影响；主 Profile、现有结构及选择状态保持可用。不自动重试或 fallback。
